Supabase SQL & Storage Guide

Run the following script in the SQL Editor of your Supabase dashboard to create the table, set defaults, and enable Row Level Security (RLS) policies.

-- 1. Announcements Table create table if not exists news ( id bigint generated by default as identity primary key, title text not null, category text not null, description text not null, published_date date default current_date, image_url text, created_at timestamp with time zone default timezone('utc'::text, now()) not null ); alter table news enable row level security; create policy "Allow public read" on news for select using (true); create policy "Allow staff insert" on news for insert with check (auth.role() = 'authenticated'); create policy "Allow staff delete" on news for delete with check (auth.role() = 'authenticated'); -- 2. Admissions Status & Site Settings Table create table if not exists site_settings ( key text primary key, value jsonb not null, updated_at timestamp with time zone default timezone('utc'::text, now()) not null ); alter table site_settings enable row level security; create policy "Allow public read site_settings" on site_settings for select using (true); create policy "Allow staff upsert site_settings" on site_settings for all using (true) with check (true); -- 3. Enable Realtime Broadcast for Instant Sync alter publication supabase_realtime add table site_settings;

Storage Bucket Setup:

  1. Go to Storage → New bucket.
  2. Name the bucket: news-images
  3. Enable "Public bucket" so uploaded news photos load on the home page.
  4. Add an insert policy on storage objects for authenticated users.
